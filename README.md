SABIA - Sistema de Inteligencia Artificial

Descripción del Proyecto



SABIA (Sistema de Inteligencia Artificial) es una plataforma desarrollada para apoyar el registro y seguimiento de alumnos alfabetizados por docentes, facilitando la gestión de información educativa mediante herramientas tecnológicas.



Objetivo



Desarrollar un sistema que permita registrar, consultar y administrar información de alumnos alfabetizados de manera eficiente, utilizando tecnologías modernas para optimizar los procesos de seguimiento y control.



Tecnologías Utilizadas

Node.js

PostgreSQL

Flutter

Git y GitHub

Postman

Swagger
